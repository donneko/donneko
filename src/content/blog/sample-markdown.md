この記事は、ブログの動作と表示を確認するための**サンプル記事**です。
実際の開発実績や技術検証の結果を示すものではありません。

## このブログについて

制作物そのものの紹介は[Works](/works/)に、開発の過程や設計上の判断はブログにまとめます。
この記事では、Markdownで使える基本的な書式を確認できます。

### 記事を書く流れ

1. `src/content/blog/` にMarkdownファイルを追加します。
2. ファイルの先頭にタイトル、概要、日付、カテゴリを書きます。
3. 本文を書き、ローカルで表示を確認します。

公開前の記事には `draft: true` を指定します。

## コードの表示例

以下は表示確認用の短いコード例です。

```ts
const message: string = "これはサンプルです";

function greet(name: string): string {
    return `${name}さん、こんにちは。${message}。`;
}

console.log(greet("読者"));
```

## 表とリストの表示例

| 項目        | 用途                     |
| ----------- | ------------------------ |
| title       | 記事のタイトル           |
| description | 一覧と検索結果向けの概要 |
| category    | 記事の分類               |
| tags        | 関連する技術や話題       |

- 見出しは本文中では `##` から始めます。
- 更新日を表示したい場合は `updatedDate` を追加します。
- インラインコードはバッククォートで囲みます。
